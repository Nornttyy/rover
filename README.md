# 移动基地

[立即游玩](https://nornttyy.github.io/rover/)

独立竖屏 Q 版丧尸探索游戏。触屏拖动移动，独立按键上下车、进屋、搜刮、上下楼和现场改装。键盘：WASD / 方向键移动、E 上下车、R 现场改装、Shift 冲撞 / 快跑、空格交互、M 地图、Escape 暂停。

街区随探索位置持续生成，无可达地图边界。动态保留附近丧尸和场景；房屋和楼层搜刮记录存档。街区使用两张完整生成的正式图片，不逐栋拼建筑，视觉结构会重复。车和人物独立生命，停车下车后车辆仍可能受到攻击。手枪自动攻击可见敌人，弹药有限。

v0.12.0：小房子 1600×1600、大房子 2400×2400、2～3 层别墅每层 2800×2800、5～8 层住宅楼每层 3200×3200（游戏世界单位）。五种完整室内场景，镜头跟随玩家，不把整层塞进一屏。靠墙双向楼梯间；每层独立物资和丧尸，顶层不能再上，1 层才能离开。物资需要 1.3 秒搜刮，移动 / 受伤取消，搜过不再刷新。

街区与室内正式图片实际是 1254×1254，角色图集 1774×887，不伪造原生 4K。近景清晰度有原图限制。图片全部存于本项目，不使用外链占位图；素材及提示词见 assets/rover/SURVIVAL-V12.md。

局内取消卡牌与经验升级，改为停车后消耗本局物资改装：机芯、炮管、火箭、装甲、引擎、磁铁、修车、包扎和弹药。局外 12 件永久装备保留，售价 180～850 零件；旧装备不补差价。成功撤离带回全部零件，失败带回35%。旧驾驶存档转为新的探索开局，保留永久金币、装备和活动载货，不导入旧卡牌。房屋内暂停街区模拟，并非离屏持续战斗。

## 开发与部署

需要 Node.js 22 或更新版本，无 npm 依赖。

```sh
npm run check
npm test
npm start
```

GitHub Pages 从 main 分支根目录自动发布，.nojekyll 保证原样提供 HTML、JavaScript 和 PNG。提交并推送 main 后网站自动更新。

游戏存档保存在当前浏览器内；不同设备、浏览器及网站域名之间不会自动同步。本站不上传玩家存档。

这是车辆游戏的独立发布目录，不包含寿司、音游或其他项目，不包含凭据或个人存档。图片是已交付的正式素材，不使用外链占位图。
