# 移动基地

[立即游玩](https://nornttyy.github.io/rover/)

独立竖屏驾驶生存肉鸽。触屏拖动驾驶，第二根手指点击冲撞；键盘使用 WASD / 方向键、Shift 冲撞、Q 脱钩、M 地图、Escape 暂停。升级时选择卡牌，停车回收可带回零件。

6144×6144 不规则城区、26 种局内升级、12 种永久改装、四节支援拖挂。局内道路、建筑、公园和车库采用一张完整生成的地图，不拼接厂区、建筑或地面摆件。基地大厅与改装工坊独立。静音、后台暂停、触控取消和本地存档均保留。

v0.9.0：district-v9.png 是实际 1254×1254 的正式整图，未插值伪造为 4K。近景由同一图片按视野裁切，小地图也使用同一张图。整图在大世界中有近景清晰度上限。旧地图版本的活动存档保留装备、经验与收入；若角色落在新车库屋顶内，会移到安全道路。

改装售价 180～850 零件，途中不能改装；旧装备无需补差价。成功撤离带回全部零件，失败带回35%。无限生存，不强制结束。

## 开发与部署

需要 Node.js 22 或更新版本，无 npm 依赖。

```sh
npm run check
npm test
npm start
```

GitHub Pages 从 main 分支根目录自动发布，.nojekyll 保证原样提供 HTML、JavaScript 和 PNG。提交并推送 main 后网站自动更新。

游戏存档保存在当前浏览器内；不同设备、浏览器及网站域名之间不会自动同步。本站不上传玩家存档。

这是车辆游戏的独立发布目录，不包含寿司、音游或其他项目，不包含凭据或个人存档。图片是已交付的正式素材，不使用外链占位图。
