# 移动基地

[立即游玩](https://nornttyy.github.io/rover/)

独立竖屏 Q 版移动基地生存肉鸽。触屏拖动移动，独立按键上下车、进屋、搜刮、上下楼和现场改装。键盘：WASD / 方向键移动、E 上下车、R 现场改装、Shift 冲撞 / 快跑、空格交互、M 地图、Escape 暂停。

街区随探索位置持续生成，无可达地图边界。动态保留附近丧尸和场景；房屋和楼层搜刮记录存档。街区使用两张完整生成的正式图片，不逐栋拼建筑，视觉结构会重复。车和人物独立生命，停车下车后车辆仍可能受到攻击。手枪自动攻击可见敌人，弹药有限。

v0.14.0：移除撤离玩法。搜房找图纸、停车改装、抵抗尸潮，然后继续探索；死亡或主动结束时结算，可随时暂停保存。第一波在街区活动 90 秒后到来，提前 8 秒预警；击杀本波所有丧尸才算清波，休整 65 秒再进入下一波。波数增加时数量、耐久和移速逐步提高，第 2 波加入远程，第 3 波及其倍数加入大型丧尸。入室暂停街区时钟，出屋继续同一波；离开远处不能抹除尸潮敌人来骗过清波。

每层首次搜刮、每次清波可找到随机装置图纸，世界中直接拾取，不弹升级卡牌。六种装置：环绕锯刃、连锁电弧、移动布雷、低温减速、伴飞无人机、贯穿激光。图纸只解锁安装资格，仍须在车旁消耗零件和元件安装，每种最多三级。本局图纸与装置跟随活动存档，下一局重置。清波奖励保留，结算时另回收 35% 剩余零件，局外永久装备保留。

继续使用 v13 正常家具比例，小房子 768×768、大房子 1024×1024、别墅与住宅楼每层 1152×1152（世界单位），不放大房屋贴图。旧存档保留已搜物资、楼层、装备、生命与收入，并从新的 90 秒尸潮准备期继续，不立刻突袭。没有更改画风，没有增加饥饿 / 燃料条。

靠墙双向楼梯间，每层独立物资和丧尸；顶层不能再上，1 层才能离开。物资需要 1.3 秒搜刮，移动 / 受伤取消，搜过不再刷新。

街区与室内正式图片实际是 1254×1254，角色图集 1774×887，不伪造原生 4K。近景清晰度有原图限制。图片全部存于本项目，不使用外链占位图；素材及提示词见 assets/rover/SURVIVAL-V12.md。

局内取消卡牌与经验升级，改为停车后消耗本局物资改装：基础火力、底盘、随机装置、修车、包扎和弹药。局外 12 件永久装备保留，售价 180～850 零件；旧装备不补差价。旧驾驶存档转为新的探索开局，保留永久金币、装备和活动载货，不导入旧卡牌。房屋内暂停街区模拟，并非离屏持续战斗。

## 开发与部署

需要 Node.js 22 或更新版本，无 npm 依赖。

```sh
npm run check
npm test
npm start
```

GitHub Pages 从 main 分支根目录自动发布，.nojekyll 保证原样提供 HTML、JavaScript 和 PNG。提交并推送 main 后网站自动更新。

游戏存档保存在当前浏览器内；不同设备、浏览器及网站域名之间不会自动同步。本站不上传玩家存档。

这是车辆游戏的独立发布目录，不包含寿司、音游或其他项目，不包含凭据或个人存档。图片是已交付的正式素材，不使用外链占位图。
